# Tracked links

Paste these exactly. The part after `?` is how `/admin` → Channels knows where a sign-up came from.
`utm_content` is the hook or post, so the Channels tab can tell which one sold.

| Where | Link |
|---|---|
| League chats (Mon) | https://penthousefantasy.com/?utm_source=friends&utm_medium=chat&utm_campaign=launch |
| Friend texts (Mon) | https://penthousefantasy.com/?utm_source=friends&utm_medium=text&utm_campaign=launch |
| Personal Facebook / Instagram / LinkedIn | https://penthousefantasy.com/?utm_source=personal&utm_medium=social&utm_campaign=launch |
| X bio | https://penthousefantasy.com/?utm_source=x&utm_medium=bio |
| Instagram / Threads / TikTok bio | https://penthousefantasy.com/?utm_source=instagram&utm_medium=bio |
| X post (swap the content tag per post) | https://penthousefantasy.com/?utm_source=x&utm_medium=post&utm_content=wire_wk4 |
| Reddit comment, when someone asks | https://penthousefantasy.com/?utm_source=reddit&utm_medium=comment |
| Creator (swap `NAME`) | https://penthousefantasy.com/?utm_source=creator&utm_medium=NAME&utm_campaign=wk4 |
| Google ads (final URL) | https://penthousefantasy.com/?utm_source=google&utm_medium=cpc&utm_campaign=startsit&utm_content={creative} |
| Reddit ads | https://penthousefantasy.com/?utm_source=redditads&utm_medium=cpc&utm_campaign=wk4&utm_content=HOOK |
| Meta ads | https://penthousefantasy.com/?utm_source=meta&utm_medium=cpc&utm_campaign=wk4&utm_content=HOOK |

`HOOK` is `clock`, `pain` or `product` (see `05-ads.md`). When you type ad spend into `/admin`, the
channel is the `utm_source` word: `google`, `redditads`, `meta`, `creator`.
